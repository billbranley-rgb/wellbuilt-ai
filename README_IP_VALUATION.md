## Source of truth

`data/k1_patent_portfolio.json` is the single source of truth. Update it
when filings, valuations, or messaging change, then regenerate:

```bash
python3 generate_ip_valuation_summary.py
```

This rewrites `output/K1_IP_Valuation_Summary.md`. The Python utility is
intentionally self-contained — it has no dependency on the existing
ReportLab deck scripts and will not break them.

## Using these files in the app / website

### Web or mobile app (JavaScript / TypeScript)

```js
const k1 = require('./src/k1Portfolio');

console.log(k1.getCleanFilings().length);         // 16
console.log(k1.getFinancialFilings().length);     // 6
console.log(k1.getVerticalFilings().length);      // 4
console.log(k1.getValuationRanges().currentPreMoney);
console.log(k1.getFilingByNumber('19/686,798'));  // tokenized rights filing
console.log(k1.getPortfolioSummary());            // everything
```

TypeScript callers get full typings via `src/k1Portfolio.d.ts`.
